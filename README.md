# Realtime Chat

Direct and group chat with live delivery over SignalR, presence, read receipts and a Redis backplane.

Work in progress; see the [roadmap](docs/ROADMAP.md).

```bash
docker compose up --build
```

API reference: http://localhost:8080/scalar
